Caixa

Tudo que é apresentado na tela, a partir do HTML, faz parte de uma caixa. Oque nós podemos fazer é manipular essas caixas, para que elas se adequem ao nosso site.
A caixa é composta por:

  • Conteúdo
  • Largura (width) e altura (height)
  • Borda (border)
  • Preenchimento (padding)
  • Margem (margin)
  • Contorno (outline)
Cada uma dessas partes de composição da caixa podem ser manipuladas, atráves do CSS, para que possamos fazer a adequação da caixa ao nosso estilo.

Tipos de caixa

Existem dois tipos de caixa, a BOX-LEVEL, e a INLINE-LEVEL. Cada uma possui uma aplicação diferente no conteúdo.

BOX-LEVEL

Esse tipo de caixa ela ocupa 100% da largura do visualizador e sempre é aplicada em uma "linha livre".

INLINE-LEVEL

Como o nome diz, essa é uma caixa que respeita a linha que ela está alocada, seguindo a sequencia de escrita na IDE e no navegador.

Aplicação das caixas

Como o restante dos elementos, podemos aplicar as caixas dentro ou fora de elementos já existentes.
Então podemos trabalhar com as caixas de várias formas, aplicando dentro de um elemento já existente, criando a caixa e adicionando elementos dentro dela, ou até mesmo colocando caixas dentro de caixas.
Para aplicarmos os dois tipo de caixa, utilizamos o elementos <div> para a BOX-LEVEL, e o elemento <span> para a INLINE-LEVEL.

TAGs de grupo | Caixas de agrupamento

Mesmo tendo elementos diretos para os dois tipos de caixa, o próprio HTML já instrui que determinados elemetos são daquele tipo específico de caixa.
Por conta disso, existem determinados elementos que nos ajudam a organizar o nosso código, assim evitamos utilizar divs e spans a todo momento, essas são as tags de grupo.

  • Cabeçalho - header
  • Menu de links - nav
  • Conteúdo - Main
  • Seção - section
  • Artigo - article
  • Complemento - aside
  • Rodapé - footer
Todas esses elementos podem ser personalizados, isoladamente, com o CSS, senão, eles irão "puxar" a mesma formatação do body.

Estilos de caixa

Como as caixas são elementos que podem ser manipulados via CSS, podemos aplicar a elas as configurações comuns do CSS, como cores, arredondamento de bordas, sombras e etc.
Fora que também podemos aplicar o CSS nas caixas com shorthands, para facilitar a escrita do código.
Algo que não é muito usual, mas que pode ser feito, é aplicar imagens como "fundo" das caixas.
