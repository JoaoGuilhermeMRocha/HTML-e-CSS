As listas ordenadas são aquelas que possuem uma ordem numérica ou alfabética, sendo representadas pela tag <ol> e utilizando <li> e </li> para cada item da lista.
Elas podem ser utilizadas para exibir informações que precisam ser apresentadas em uma sequência específica, como etapas de um processo ou uma lista de prioridades.
Podemos personalizar o tipo de lista com o atributo "type", dentro da tag <ol>, que pode assumir os valores "1" (números), "A" (letras maiúsculas), "a" (letras minúsculas), "I" (números romanos maiúsculos) e "i" (números romanos minúsculos).

<ol type="1">
lista
</ol>

As listas não ordenadas são aquelas que não possuem uma ordem específica, sendo representadas pela tag <ul> e utilizando <li> e </li> para cada item da lista.
Elas podem ser utilizadas para exibir informações que não precisam ser apresentadas em uma sequência específica, como uma lista de compras ou uma lista de tarefas.
Podemos personalizar o tipo de marcador com o atributo "type", dentro da tag <ul>, que pode assumir os valores "disc" (círculo preenchido), "circle" (círculo vazio) e "square" (quadrado preenchido).

<ul type="disc">
lista
</ul>

As listas aninhadas são aquelas que possuem uma lista dentro de outra lista, sendo representadas pela combinação das tags <ol> e <ul>.
Elas podem ser utilizadas para exibir informações que possuem uma hierarquia ou uma relação de dependência, como uma lista de tópicos e sub-tópicos.
Podemos personalizar o tipo de lista e o tipo de marcador das listas aninhadas da mesma forma que as listas ordenadas e não ordenadas. Fora o fato de podermos utilizar o atributo "start" em cada nível, para definir o número inicial de cada lista isoladamente.

<ul start="1">
lista
</ul>

As listas de definição são aquelas que possuem termos e suas respectivas definições, sendo representadas pela tag <dl>, utilizando as tags <dt> e </dt> para os termos e <dd> e </dd> para as definições .
Elas podem ser utilizadas para exibir informações que precisam ser apresentadas em pares, como uma lista de palavras e seus significados ou uma lista de perguntas e respostas.

<dl>
<dt>Termo 1</dt>
<dd>Definição do termo 1</dd>
</dl>
