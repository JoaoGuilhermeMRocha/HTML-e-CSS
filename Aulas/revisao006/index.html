Principais Formatações de Texto

Negrito

Para deixarmos uma palavra ou frase em negrito a tag utilizada é:<strong>.

Itálico

Para deixarmos uma palavra ou frase em itálico a tag utilizada é:<em>.

Marcador de texto

Para deixarmos uma palavra ou frase marcada a tag utilizada é:<mark>.

Tamanho de texto

Para deixarmos uma palavra ou frase com tamanho de texto diferente a tag utilizada é:<small>.

Riscado

Para deixarmos uma palavra ou frase riscada a tag utilizada é:<del>.

Sublinhado

Para deixarmos uma palavra ou frase sublinhada a tag utilizada é:<ins>.

Subscrito e Sobrescrito

Para deixarmos uma palavra ou frase subscrita a tag utilizada é:<sub>.

Para deixarmos uma palavra ou frase sobrescrita a tag utilizada é:<sup>.

Código-fonte

Para deixarmos uma palavra ou frase com formatação de código-fonte a tag utilizada é:<code>.

Pré-formatado

Para deixarmos uma palavra ou frase com formatação pré-formatada a tag utilizada é:

                <pre>.

Citação

Para deixarmos uma palavra ou frase com formatação de citação simples a tag utilizada é:<q>.

Para deixarmos uma palavra ou frase com formatação de citação em bloco a tag utilizada é:

<blockquote>.

Abreviação

Para deixarmos uma palavra ou frase com formatação de abreviação a tag utilizada é:<abbr>.
