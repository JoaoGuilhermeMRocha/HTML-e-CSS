Para oque serve, a tipografia?

A tipografia é, básicamente, o estudo da escolha e do arranjo de fontes para fins comunicativos. A partir dela, é possível criar designs que melhoram a legibilidade e a estética de um texto.
Assim como as cores, a tipografia também pode transmitir emoções e influenciar a percepção do conteúdo. A escolha da fonte, o tamanho, o espaçamento e o estilo podem impactar a forma como uma mensagem é recebida pelo público. Como por exemplo, a caligrafia de uma professora de português, geralmente, é mais legível, clara, e fácil de ler, do que a caligrafia de um professor de matemáttica, que geralmente é mais difícil de ler, e menos clara. Isso se aplica também para as fontes digitais, ou impressas, que podem ser mais ou menos legíveis, dependendo de sua escolha e aplicação.

Tipos de fontes

Existem diversos tipos de fontes, cada uma com suas características e propósitos. As principais categorias incluem:

  • Serifadas: Possuem pequenos traços ou "serifas" nas extremidades das letras. São frequentemente associadas a uma aparência clássica e tradicional.
  • Sem serifa (Sans-serif): Não possuem serifas, resultando em um visual mais limpo e moderno. São amplamente utilizadas em interfaces digitais.
  • Manuscritas (Handwriting/Script): Imitam a escrita à mão, transmitindo uma sensação de personalidade e informalidade.
  • Monoespaçadas (Monospace): Cada caractere ocupa o mesmo espaço horizontal, sendo comumente usadas em programação e design técnico.
  • Decorativas: Possuem estilos únicos e chamativos, sendo usadas para criar impacto visual em títulos e elementos gráficos.
Cada tipo de fonte pode ser escolhida com base no contexto e na mensagem que se deseja transmitir. A combinação adequada de fontes também é importante para criar hierarquia visual e melhorar a experiência do usuário.

Como aplicar a tipografia no CSS

Podemos usar a propriedade "font-family" no CSS para definir a fonte de um elemento, especificando uma lista de fontes alternativas, caso a primeira não esteja disponível.
Por exemplo: font-family: Arial, Helvetica, sans-serif; - Nesse caso, o navegador tentará usar a fonte Arial. Se não estiver disponível, ele tentará Helvetica e, se nenhuma das duas estiver disponível, ele usará uma fonte sem serifa genérica.

Editando as fontes

Tamanho da fonte

A propriedade "font-size" é utilizada para definir o tamanho da fonte de um elemento. Ela pode ser especificada em diferentes unidades, como pixels (px), pontos (pt), porcentagens (%), entre outras. Porém, o mais recomendado é utilizar px, quando sabemos em que tipo de dispositivo, ou tela, o conteúdo será exibido, pois essa é uma unidade absoluta, ou seja, não muda conforme o tamanho da tela ou o zoom do navegador. Agora, quando não sabemos o tamanho exato, podemos utilizar em, que é uma unidade relativa, e se adapta ao tamanho da tela, sempre com base na fonte padrão do código.

Peso da fonte

A propriedade "font-weight" é utilizada para definir o peso da fonte de um elemento. Ela pode ser especificada como: "lighter", "normal", "bold", "bolder", ou valores numéricos entre 100 e 900. Mas não são todas as fontes que suportam todos esses valores, o mais comum de ser aceito pelas fontes são "normal" e "bold", ou em valores numéricos, de 400 a 700. A nível de comparação, "normal" é equivalente a escrita comum dos editores de texto, enquanto "bold" é equivalente ao negrito.

Estilos da fonte

A propriedade "font-style" é utilizada para definir o estilo da fonte de um elemento. Ela pode ser especificada como: "normal", "italic" e "oblique". O valor "normal" é o estilo padrão, enquanto "italic" e "oblique" são estilos itálicos, sendoo que com o "oblique", podemos definor o grau de inclinação da fonte.
A propriedade "text-decoration" é utilizada para adicionar decorações ao texto, como sublinhado, linha sobre o texto ou linha através do texto. Ela pode ser especificada como: "none", "underline", "overline" e "line-through". O valor "none" remove qualquer decoração existente, enquanto os outros valores adicionam a decoração correspondente.

Facilidando a nossa vida

Podemos muito bem criar classes no CSS, para espeficicando cada configuração isoladamente, por exemplo: 

                    
                        h1 {
                        font-family: Arial, Helvetica, sans-serif;
                        font-size: 3em;
                        font-weight: bold;
                        font-style: italic;
                        }
Ou podemos criar uma classe, de uma só linha, que engloba todas as configurações, por exemplo: 
                    
                        h1 {
                        font: italic bold 3em Arial, Helvetica, sans-serif;
                        }
Isso é um "shorthand", uma função que agiliza o trabalho, mas deve sempre seguir a sintaxe => font: [estilo] [peso] [tamanho] [família de fontes - separadas por vírgula];
Onde os valores entre colchetes são opcionais, mas a ordem deve ser respeitada.

Alinhamento das fontes

A propriedade "text-align" é utilizada para definir o alinhamento do texto dentro de um elemento. Ela pode ser especificada como: "left", "right", "center" e "justify". O valor "left" alinha o texto à esquerda, "right" alinha à direita, "center" centraliza o texto e "justify" justifica o texto, ajustando o espaçamento entre as palavras para que as linhas fiquem alinhadas tanto à esquerda quanto à direita.
Temos tambbém a propriedade "text-indent", que é utilizada para definir a indentação da primeira linha de um parágrafo. Ela pode ser especificada em diferentes unidades, como pixels (px), pontos (pt), porcentagens (%), entre outras. O valor positivo aumenta a indentação, enquanto o valor negativo reduz a indentação.
