Imagens dinâmicas

Podemos ajustar o tamanho das imagens dinamicamente, dependendo do tamanho da tela do dispositivo, diretamente no código HTML.
Para isso, utilizados o atributo <picture> e <source>, dentro do código. Definindo diferentes fontes para diferentes tamanhos de tela.
Vale lembrar que o atributo deve ser definido, da menor para a maior resolução, senão a imagem mais adequada não será carregada.

Áudios

Para adicionar áudios em uma página HTML, utilizamos a tag <audio>, e o atributo <source>, definindo o tipo de arquivo que será reproduzido.
Podemos utilizar alguns outros atributos também, como por exemplo:

  • controls - Mostra o controle de áudio midia
  • preload - Difine oque será carregado junto da página
    • auto - carrega todo o arquivo, demorando mais para carregar a página. NÃO RECOMENTANDO
    • metadado - apenas as informações base do arquivo, pesando menos no carregamento inicial da página.
    • none - não carrega nada.
  • loop - Toca o áudio em loop
  • autosplay - Carrega a página com o áudio tocando

Vídeos

Para adicionar vídeos, utilizamos a tag <video>, e o atributo <source>. Os vídeos se compartam similiar aos áudios, podemos utilizar os atributos listas anterioremente aqui também. Podemos usar width também, mas nesse exemplo que usei, ao tentar usar ele na tag de vídeo, meu xablau.
Apenas devemos nos atentar, ao tipo de vídeo que será carregado e seu tamanho, para que não pesemos de mais o site, e temanhos certeza que aquele formato escolhido é aceito pela maioria dos navegadores.

Vídeos incorporados

Também é possível usar mídias incorporadas, direto do Youtube, Spotify, Vimeo, GoogleDrive e etc. Para isso usamos <iframe>, com os mesmos atributos de antes.
Essa opção não consome armazenamento interno do equipamento que o código está alocado, e também pode ser mais fácil de utilizar, o Youtube já gera o a tag do iframe direto quando necessário, através da opção de compartilhar e incorporar.
IMPORTANTE! O Youtube bloqueia a incorporação de vídeos para htmls hospedados diretamente em máquinas, como no caso dessas revisões, por conta disso tive que usar a extensão "Live Server" do VSCode, e abrir o index.html com a extensão, somente dessa forma a incorporação funcionou.
