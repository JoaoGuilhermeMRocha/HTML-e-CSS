Links externos

Os links externos são utilizados para direcionar o usuário para páginas web em outros domínios. Utilizamos o atributo <href> para especificar a URL da página para a qual queremos redirecionar o usuário.
Também podemos utilizar links externos para abrir páginas em uma nova aba do navegador, utilizando o atributo <target> com o valor _blank, especificando com <rel> igual a external, para definir no código oque será aberto em nova guia, mantendo a nossa em aberto.

Links de download

Para disponibilizar um arquivo para download, utilizamos o atributo <href>, e depois o atributo download="nome-do-arquivo".
Pode ser necessário, utilizar o atributo <type> para especificar o tipo de arquivo que será baixado, como por exemplo: application/pdf, image/png, text/plain, entre outros. Para saber qual type utilizar, podemos validar em IANA Media Types

Clique no link ao lado realizar o download, da foto do gato mais lindo do mundo: Foto do gato
Clique no link ao lado realizar o download, de uma pasta .zip, de mais gatos lindos: Pasta de gatos
