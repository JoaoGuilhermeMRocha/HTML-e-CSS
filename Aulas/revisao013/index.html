ID e Class

ID

Podemos segmentar elementos usando o atributo "id", por exemplo:
No site temos dois h1, e queremos que cada um tenha uma cor diferente. Para fazer isso, podemos diferenciar eles como <h1 id="titulo1"> e <h1 id="titulo2">
E no CSS, podemos definir a cor de cada um usando o seletor de ID, h1#titulo1 {} e h1#titulo2 {}
No HTML, classificamos o elemento com id=, mas no CSS, traduzimos esse classificador para #.

Mas temos um porém no uso do ID, que é o fato de que ele só pode ser usado uma vez por página, ou seja, não podemos ter dois elementos com o mesmo ID. Por isso, quando queremos aplicar a mesma configuração para vários elementos, devemos usar o atributo "class".

Class

Podemos segmentar elementos usando o atributo "class", por exemplo:
No site temos vários h2, e queremos que alguns tenham certas propriedades, e outros, tenham outras propriedades. Então, podemos diferenciar eles como <h2 class="conjunto1"> e <h2 class="conjunto2">
E no CSS, podemos definir as suas propriedades com .conjunto1 {} e .conjunto2 {}
No HTML, classificamos o elemento com class=, mas no CSS, traduzimos esse classificador para ., sem a necessidade de colocar o nome do elemento antes do ponto.
Ao utilizar a class, nós não estamos limitados a um único elemento, ou seja, podemos ter vários elementos com a mesma class. Por conta disso, podemos aplicar .conjunto1, ou o .conjunto2, a outras partes do HTML. Para fazer isso, usamos <span class=""> Lorem </span>.

Com o class, vários elementos podem ter a mesma classificação.

Nós também podemos unir o uso de ID e class, colocando ambos dentro do mesmo <>. Porém o ID sempre irá se sobresair a class. <p id="" class="">Lorem</p> Também podemos unir mais de uma class dentro do mesmo <>, elas só devem ser separadas com um espaço entre elas. <p class="class1 class2">Lorem</p>

Pseudo-classes

As pseudo-classes são classes especiais que podem ser aplicadas dentro do CSS. Elas são representadas por um ":pseudo-classe", após a uma classe já definida.
Dessa forma, podemos aplicar condições especiais aos elementos, como por exemplo, quando o mouse estiver sobre eles, ou quando forem clicados.
Com as pseudo-classes também podemos definir ordens. Por exemplo, um paragrafo que esteja dentro de um elemento, pode ser diferente de outro paragrafo, do mesmo elemento, que esteja em outra posição. Para isso podemos usar elemento ou classe, fazendo com que a pseudo-classe que esteja após a isso, só seja aplicado com essas condições dentro do HTML.

Pseudo-elementos

Os pseudo-elementos são elementos especiais que podem ser aplicados dentro do CSS. Eles são representados por um "::pseudo-elemento", após a um elemento que esteja em uso no HTML, ou até mesmo a uma classe já definida.
