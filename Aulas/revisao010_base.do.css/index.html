Oque é o CSS?

CSS significa Folhas de estilo em cascata, e como o HTML, elas não são uma linguagem de programação em si. Nós utilizamos as CSS para dar uma "cara" para o nosso site/sistema.
Para utilizarmos as CSS, usamos a tag <style>, e seus atributos. Como as CSS possuem muitos atributos, e bota MUITOS nisso, a maioria a gente vai ter que ir descobrindo com o tempo. Mas os principais são:

  • color - cor da fonte
  • background-color - cor da página em si
  • font-size - tamanho da fonte
  • font-family - tipo da fonte
  • text-align - alinhamento

Estilos inline

Estilos inline são aqueles que colocamos diretamente nas funções e atributos, definindo cada um individualmente. Isso não é recomendando para definir o estilo do site/sistema como um todo, pois será necessário atualizar linha por linha em casos de alteração, fora o fato de misturarmos estilo e conteúdo em uma coisa só, sendo que a convesão é separarmos cada uma dessas coisas, dentro do código.

Esse é um exemplo de estilo inline, onde o paragrafo está sendo escrito da seguinte forma:
<p style="color: darkblue;"> Texto...

Estilos internos

Os estilos internos são colocados diretamente na head do código, logo abaixo do tittle. Quando usamos essa opção, seguimos utilizando o style com cada uma das suas opçãoes de configuração. Dessa forma organizamos melhor o código, e podemos fazer alterações gerais, caso necessário.
Com essa opção, definimos os estilos da seguinte maneira: 

            <head>
                <style>
                    body {backgroud-color: darkblue;
                    font-family: arial;
                    font-size: 20px;
                    }
                </style>
            </head>

Esse tipo de estilo funciona muito bem para casos em que temos somente uma página, não um ambinte mais completo, pois teriamos que escrever o style em todas as páginas do ambiente, oque seria um saco, mesmo usando crtl+v e crtl+v. Fora o fato da head ficar extremamente comprida e o body ficar lááá em baixo no VSCode.

Estilos externos

Esse aqui é o bala!
Os estilos externos são os mais versateis de utilizarmos. Aqui nós não inserimos o style no body ou head do código, mas sim em um arquivo externo.
Aqui nós vamos fazer um link, da mesma forma que fazemos com o ícone, mas dessa vez com o style. Dessa forma aqui: 

            <head>
            ...
            <title>
            <link rel="stylesheet" href="arquivo.css">
            </head>

Dessa forma, podemos configurar todo o estilo em um único lugar, e replica-lo livremente nas páginas e ambientes.

Alguns adendos, é importante que o arquivo .css inicie com '@charset "UTF-8";', dessa forma indicamos que as CSS se adequem a nossa linguagem. Também podemos mesclar os tipos de estilo, sendo que a ordem em que os estilos se sobressaem é: inline > local > externo.
