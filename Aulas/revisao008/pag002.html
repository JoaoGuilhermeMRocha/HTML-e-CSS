Links internos

Os links internos são utilizados para navegar entre as páginas do mesmo site. Utilizamos o atributo <href> para especificar o caminho da página para a qual queremos redirecionar o usuário.
Neste caso não usamos o atributo target="_blank", pois estamos navegando no nosso site mesmo, apenas em páginas diferentes, e para indicar isso usamos target="_self". E como estamos no nosso site, o rel; será igual a next, ou prev, caso queiramos indicar um link que "voltara para trás".
Caso queiramos indicar um link que não deve ser lido pelo mecanismo de busca, podemos usar o atributo rel="nofollow".
